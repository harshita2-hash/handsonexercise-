# TDD using JUnit 5 and Mockito

## Overview
This folder contains hands-on exercises on Test-Driven Development (TDD) using JUnit 5 and Mockito as part of the Cognizant Digital Nurture Program. The exercises demonstrate writing unit tests, creating mock objects, and validating application behavior.

## Objectives
- Understand the principles of Test-Driven Development (TDD)
- Write unit tests using JUnit 5
- Mock dependencies using Mockito
- Improve code quality through automated testing

## Topics Covered
- Introduction to TDD
- JUnit 5 Annotations
- Assertions
- Test Lifecycle Methods
- Parameterized Tests
- Exception Testing
- Mockito Basics
- Mocking Objects
- Stubbing Methods
- Verifying Method Calls
- Dependency Injection with Mockito
- Unit Testing Best Practices

## Technologies Used
- Java
- JUnit 5
- Mockito
- Maven
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Ensure Maven dependencies are downloaded.
4. Run the test classes as **JUnit Tests**.
5. Verify that all test cases pass successfully.

## Learning Outcomes
- Apply Test-Driven Development practices.
- Write effective unit tests using JUnit 5.
- Use Mockito to isolate and test components.
- Improve software reliability through automated testing.
