# Spring Core and Maven

## Overview
This folder contains hands-on exercises on Spring Core and Maven completed as part of the Cognizant Digital Nurture Program. The exercises demonstrate the fundamentals of the Spring Framework, dependency injection, bean configuration, and Maven project management.

## Objectives
- Understand the fundamentals of Spring Core
- Configure and manage Spring Beans
- Implement Dependency Injection (DI)
- Learn Inversion of Control (IoC)
- Build and manage Java projects using Maven

## Topics Covered
- Spring Framework Introduction
- Inversion of Control (IoC)
- Dependency Injection (DI)
- Spring Beans
- Bean Scope
- Bean Lifecycle
- XML-Based Configuration
- Annotation-Based Configuration
- Constructor Injection
- Setter Injection
- Maven Project Structure
- Maven Dependencies
- Maven Build Lifecycle
- pom.xml Configuration

## Technologies Used
- Java
- Spring Core
- Apache Maven
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Import the project as an **Existing Maven Project**.
4. Allow Maven to download all required dependencies.
5. Run the main application class.
6. Verify the application output in the console.

## Learning Outcomes
- Understand the architecture of the Spring Framework.
- Implement Dependency Injection using Spring.
- Configure beans using XML and annotations.
- Manage project dependencies using Maven.
- Build and execute Maven-based Spring applications.
