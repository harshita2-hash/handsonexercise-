# Spring REST using Spring Boot 3

## Overview
This folder contains hands-on exercises on building RESTful web services using Spring Boot 3 as part of the Cognizant Digital Nurture Program. The exercises demonstrate how to create, test, and manage REST APIs using Spring Boot.

## Objectives
- Understand RESTful Web Services
- Build REST APIs using Spring Boot 3
- Handle HTTP requests and responses
- Implement CRUD operations
- Test REST APIs using Postman

## Topics Covered
- Introduction to REST API
- Spring Boot 3 Fundamentals
- REST Controllers
- HTTP Methods (GET, POST, PUT, DELETE)
- Request Mapping
- Path Variables
- Request Parameters
- Request Body
- ResponseEntity
- Exception Handling
- Validation
- JSON Data Handling
- Spring Boot Auto Configuration
- REST API Testing with Postman

## Technologies Used
- Java
- Spring Boot 3
- Spring Web
- Maven
- Postman
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Import the project as a Maven project.
4. Update Maven dependencies.
5. Run the Spring Boot application.
6. Test the REST endpoints using Postman or a web browser.

## Learning Outcomes
- Develop RESTful web services using Spring Boot 3.
- Implement CRUD operations with REST APIs.
- Handle client requests and server responses effectively.
- Test and debug REST APIs using Postman.
- Build scalable and maintainable backend applications.
