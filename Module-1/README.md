# Design Patterns

## Overview
This module contains hands-on exercises and examples of Design Patterns implemented as part of the Cognizant Digital Nurture Program.

## Objectives
- Understand the concept of Design Patterns
- Learn different categories of Design Patterns
- Improve software design and code reusability
- Apply Design Patterns in Java applications

## Topics Covered
- Singleton Pattern
- Factory Pattern
- Abstract Factory Pattern
- Builder Pattern
- Prototype Pattern
- Adapter Pattern
- Decorator Pattern
- Facade Pattern
- Proxy Pattern
- Observer Pattern
- Strategy Pattern
- Command Pattern
- Template Method Pattern

## Technologies Used
- Java
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile and run the required Java class.
4. Observe the output for each Design Pattern implementation.

## Learning Outcomes
- Understand object-oriented design principles.
- Implement commonly used Design Patterns.
- Improve code maintainability and flexibility.
- Gain practical experience with Java Design Patterns.
