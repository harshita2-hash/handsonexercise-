# Module 1 – Git Fundamentals

## Overview
This module contains hands-on exercises covering the fundamentals of Git and GitHub.

## Objectives
- Install and configure Git
- Create and initialize a Git repository
- Track files using Git
- Commit changes
- Work with local and remote repositories
- Learn basic Git commands

## Hands-on Exercises Completed
- Git installation and configuration
- Repository initialization (`git init`)
- Creating and tracking files
- Checking repository status (`git status`)
- Adding files (`git add`)
- Committing changes (`git commit`)
- Viewing commit history (`git log`)
- Connecting to a remote GitHub repository
- Pulling changes (`git pull`)
- Pushing changes (`git push`)

## Git Commands Used

```bash
git --version
git config --global user.name
git config --global user.email
git init
git status
git add .
git commit -m "Initial commit"
git log
git remote add origin <repository-url>
git pull origin main
git push -u origin main
```

## Technologies Used
- Git
- GitHub
- Git Bash
- Windows
