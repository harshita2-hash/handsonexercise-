# Microservices with Spring Boot 3 and Spring Cloud

## Overview
This folder contains hands-on exercises on developing Microservices using Spring Boot 3 and Spring Cloud as part of the Cognizant Digital Nurture Program. The exercises demonstrate how to build, deploy, and manage scalable microservices-based applications.

## Objectives
- Understand Microservices Architecture
- Develop Microservices using Spring Boot 3
- Implement Service Discovery with Eureka
- Configure API Gateway
- Enable Inter-Service Communication
- Implement Centralized Configuration
- Build Fault-Tolerant Microservices

## Topics Covered
- Introduction to Microservices
- Spring Boot 3
- Spring Cloud
- Eureka Server
- Eureka Client
- API Gateway
- Config Server
- OpenFeign Client
- Load Balancing
- Circuit Breaker (Resilience4j)
- Service Discovery
- Distributed Configuration
- RESTful Communication
- Microservices Deployment

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Import the project as a Maven project.
4. Update Maven dependencies.
5. Start the Config Server (if available).
6. Start the Eureka Server.
7. Start the Microservices.
8. Start the API Gateway.
9. Test the APIs using Postman or a web browser.

## Learning Outcomes
- Understand Microservices architecture and its benefits.
- Build and deploy Microservices using Spring Boot 3.
- Register and discover services using Eureka.
- Route requests through Spring Cloud Gateway.
- Implement inter-service communication using OpenFeign.
- Improve application resilience using Resilience4j.
- Develop scalable and maintainable distributed applications.
