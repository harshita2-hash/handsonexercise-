# Spring Data JPA with Spring Boot and Hibernate

## Overview
This folder contains hands-on exercises on Spring Data JPA with Spring Boot and Hibernate completed as part of the Cognizant Digital Nurture Program. The exercises demonstrate how to build database-driven applications using Spring Boot, Hibernate, and JPA for efficient data persistence.

## Objectives
- Understand Spring Data JPA concepts
- Perform CRUD operations using JPA repositories
- Integrate Hibernate with Spring Boot
- Map Java entities to database tables
- Build RESTful applications with database connectivity

## Topics Covered
- Spring Boot Fundamentals
- Spring Data JPA
- Hibernate ORM
- Entity Mapping
- CRUD Operations
- JpaRepository
- Custom Queries
- Relationships (One-to-One, One-to-Many, Many-to-One, Many-to-Many)
- JPQL
- Native SQL Queries
- Pagination and Sorting
- Transactions
- Exception Handling
- MySQL Database Integration

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- MySQL
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in Eclipse or IntelliJ IDEA.
3. Import the project as a Maven project.
4. Configure the MySQL database connection in `application.properties`.
5. Update Maven dependencies if required.
6. Run the Spring Boot application.
7. Test the application using Postman or a web browser.

## Learning Outcomes
- Build Spring Boot applications with database support.
- Implement CRUD operations using Spring Data JPA.
- Use Hibernate for Object-Relational Mapping (ORM).
- Create efficient and maintainable database-driven applications.
- Understand entity relationships and transaction management.
