# PL/SQL

## Overview
This folder contains PL/SQL hands-on exercises completed as part of the Cognizant Digital Nurture Program. The programs demonstrate database programming concepts using Oracle PL/SQL.

## Objectives
- Understand PL/SQL programming fundamentals
- Develop stored procedures and functions
- Work with cursors, triggers, and exception handling
- Perform database operations efficiently

## Topics Covered
- PL/SQL Blocks
- Variables and Data Types
- Conditional Statements (IF, CASE)
- Loops (FOR, WHILE, LOOP)
- Cursors
- Stored Procedures
- Functions
- Packages
- Triggers
- Exception Handling
- Collections
- Transactions

## Technologies Used
- Oracle Database
- PL/SQL
- SQL Developer
- Git
- GitHub

## How to Run
1. Open Oracle SQL Developer.
2. Connect to your Oracle Database.
3. Open the required `.sql` file.
4. Execute the script using **Run Script (F5)** or **Run Statement (Ctrl + Enter)**.
5. Verify the output and database changes.

## Learning Outcomes
- Understand PL/SQL programming concepts.
- Develop reusable database procedures and functions.
- Handle exceptions and database transactions effectively.
- Implement database triggers and cursor-based processing.
