# Data Structures and Algorithms (DSA)

## Overview
This folder contains hands-on exercises and implementations of Data Structures and Algorithms completed as part of the Cognizant Digital Nurture Program. The programs demonstrate fundamental concepts used in problem-solving and software development.

## Objectives
- Understand core Data Structures and Algorithms
- Improve problem-solving and logical thinking
- Learn algorithm analysis and time complexity
- Implement DSA concepts using Java

## Topics Covered
- Arrays
- Strings
- Linked Lists
- Stacks
- Queues
- Trees
- Binary Search Trees (BST)
- Graphs
- Searching Algorithms
- Sorting Algorithms
- Recursion
- Greedy Algorithms
- Dynamic Programming
- Backtracking

## Technologies Used
- Java
- Eclipse / IntelliJ IDEA
- Git
- GitHub

## How to Run
1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile and run the required Java program.
4. Observe the output for each DSA implementation.

## Learning Outcomes
- Understand fundamental Data Structures and Algorithms.
- Analyze algorithm efficiency using time and space complexity.
- Develop optimized solutions for programming problems.
- Strengthen coding and problem-solving skills.
