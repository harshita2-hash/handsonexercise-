# Angular Hands-on Exercises

## Overview
This folder contains Angular hands-on exercises completed as part of the Cognizant Digital Nurture Program. The exercises cover Angular fundamentals, components, modules, data binding, directives, services, routing, forms, and other core concepts.

## Objectives
- Understand Angular project structure
- Create and manage Angular components
- Implement data binding and directives
- Work with services and dependency injection
- Configure routing between components
- Build forms using Angular
- Practice Angular CLI commands

## Technologies Used
- Angular

- HTML
- CSS
- Node.js
- Angular CLI

## How to Run

1. Install Node.js and Angular CLI.
2. Clone the repository.
3. Navigate to the Angular project folder.
4. Install dependencies:

```bash
npm install
```

5. Start the development server:

```bash
ng serve
```

6. Open the browser and visit:

```
http://localhost:4200/
```
